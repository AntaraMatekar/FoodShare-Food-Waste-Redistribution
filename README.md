# # FoodShare – Food Waste Redistribution System

## Project Overview
FoodShare is a web-based system that connects food donors
with receivers to help redistribute surplus food.

## Technologies
- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript

## Features
- User Registration/Login
- Donor Dashboard
- Receiver Dashboard
- Food Donation
- Food Search
- Smart Matching
- Food Requests
- Request Approval/Rejection

## How to Run

pip install -r requirements.txt

python app.py

Open:
http://127.0.0.1:5000-Food-Waste-Redistribution
